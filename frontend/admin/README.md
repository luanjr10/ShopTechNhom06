# ShopTech · Admin & Seller Center

Ứng dụng quản trị sàn và kênh người bán, giao diện thay đổi theo vai trò (React 19 + Vite + Tailwind CSS 4 + Chart.js).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Giao diện phát triển dựa trên template [Mosaic Lite](https://github.com/cruip/tailwind-dashboard-template) (Cruip).

Xem tổng quan dự án tại [README gốc](../../README.md).
